# Waypost brand

Waypost is an independent local utility for Proton users connecting Mail, Drive, and Calendar handoffs to an agent. Its public headline is “Mail and files. Calendar handoffs.”

The original mark is a wayfinding post: three routes meet at one local junction. The same geometry appears in the documentation diagram. Keep the routes and their service limits visible; a shared interface does not mean shared authentication.

| Token | Color | Use |
| --- | --- | --- |
| Midnight navy | `#172331` | Type, primary actions, dark backgrounds |
| Warm ivory | `#f3f0e7` | Page and reversed type |
| Muted vermilion | `#cc6949` | Route lines and illustration |
| Dark vermilion | `#a3482e` | Small accent text and focus rings |
| Slate | `#59616a` | Secondary text |

Use the system sans stack for prose and system monospace for commands. No downloaded fonts, external assets, framework, tracking, or Proton marks are used. Preserve generous margins, fine rules, square controls, and a short reading path: service routes, source setup, MCP configuration, boundaries.

## Assets

- `assets/mark.svg`: editable 96-unit transparent mark in navy.
- `assets/icon.svg` and `assets/favicon.svg`: ivory mark on a navy tile.
- `assets/icon.png`: 512 × 512 transparent-corner PNG export of the icon SVG, suitable for plugin use.
- `assets/github-banner.svg`: 1280 × 640 repository banner.
- `assets/site-preview.jpg`: 1280 × 920 capture of the final landing page, used by the personal-site project entry.
- `assets/site-preview.svg`: 1280 × 800 vector illustration of the documentation page; not a runtime screenshot.

All geometry and compositions were authored for this project. System fonts are referenced, not redistributed. The SVG source remains editable.

## Claims and reference choices

Show Mail through Bridge IMAP, Drive through the official CLI, and Calendar through ICS snapshots and prepared imports. Call the project beta. State independence from Proton. Never imply a live Calendar API, shared headless login, or a security/compliance guarantee.

Reference inspection on 2 October 2026: [GitHub CLI](https://cli.github.com/) for immediate installation access and [Git](https://git-scm.com/) for a compact open source documentation hierarchy. Waypost uses its own mark, colors, copy, and layout.
