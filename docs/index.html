Three services. Three routes.

Each uses a route Proton documents.

ServiceRouteWhat to expect
MailLocal Proton Mail BridgeRead mail over IMAP. Bridge requires a paid Mail plan.
DriveOfficial Proton Drive CLIList, inspect, download, and optionally upload through the official CLI.
CalendarICS snapshots + prepared importsRead snapshots. Prepare files for manual import into Proton Calendar.

Connect your agent.

Node.js 22.14+ · Source setup

01Build and check the local setup

Terminal
git clone https://github.com/baney75/waypost
cd waypost
npm ci --ignore-scripts
npm run build
node dist/cli.js init
node dist/cli.js tools

Connect one service using the setup guide, then run node dist/cli.js doctor. Set up Bridge and the Drive CLI separately. Follow the service setup notes for requirements.

02Add Waypost to your MCP client

MCP client configuration
{
  "mcpServers": {
    "waypost": {
      "command": "node",
      "args": [
        "/absolute/path/to/waypost/runtime/waypost.mjs",
        "mcp"
      ]
    }
  }
}

Use node dist/cli.js agent-config generic to print your paths. Mail sends and Drive uploads start disabled.

Know the handoff.

Waypost runs locally; data passed to an agent follows that agent’s own data policies. Calendar uses files, not a live Calendar API. An import file becomes a saved event only after you import it. Review security guidance and service boundaries before connecting.
